# 《飞 Fly》制作过程公开

这里是视觉小说《飞 Fly》的制作材料：剧本的初稿与改稿、一版版的动态分镜、给 AI 的提示词与交接文档、和 AI 的对话节选。

游戏本体与源代码在另一个仓库：[IEndndI/Fly](https://github.com/IEndndI/Fly)。

## 写在前面

《飞》来自我很多年前做过的一个梦。醒来以后，那种说不出来的感觉一直卡在喉咙里，我想把它写下来，后来又想让它动起来。

我是一名学生。这个国庆，我想试试一个人加上 AI，七天之内能把一个梦做成什么样子。AI参与了很多，整体算下来，AI 参与了大约六成。

我知道很多人讨厌 AI 参与创作，我也理解。认真手写的作者因为 AI 被怀疑、被「鉴」，读者被冒充手写的 AI 作品骗，这些都是真的，我自己也是写字的人。在我看来，用 AI 本身不可耻，藏起来才是问题。所以我把能摊开的都摊开了：

- 剧本从初稿到改稿的样子，AI 在哪里提过意见，哪些我收下了，哪些我没要；
- 动态分镜一版一版改过来的过程；
- 给 AI 的提示词，还有中途换模型时写的交接文档；
- 我和 AI 的对话：我怎么提要求，哪里说了「不对，重来」。

公开这些，一是想让你自己判断，这部作品里哪些是我的，哪些是 AI 的。你可以不喜欢它，但它是明码标价的。二是想留给想学的人：如果你也想做一部自己的视觉小说，却因为不会画、不会写程序迟迟没开始，这里有一条我真实走过的路，坑也都在里面。

我很爱 FVN 这个圈子。有一部写了好几年的长篇，我一直没敢发出来；《飞》是我第一次真正把一个作品做完、交出去。它很短，也很粗糙，立绘都还没画完。可它是我的梦。

如果你读到了这里，谢谢你。

<sub>这段文字由 Claude 根据我在对话里说过的话、按我的口吻整理，我读过并认可。（Endnd）</sub>

## 创作意图

《飞》讲一个男孩两次使用滑翔机的故事：第一次，他飞到了宇宙之外；许久以后的第二次，他没能飞起来。

我想表达的东西很难说清楚。尽量说的话，大概有四层：

说不清的失去 + 无法言说的痛苦 + 对年轻自己的温柔 + 一种轻盈的、几乎不带解释的继续。

它是一篇童话。两个结局没有对错，同样重要，各自抒发不一样的东西；做成视觉小说，选择本身就是玩法的一部分。我也不想让它变成一个讨论成功与失败、或者和别人比较的故事，它从我自己出发，再往外延伸。我想留住的，是那种一切缓缓变化、抓不住、说不清的感觉。

| 动态分镜（HTML）、画面动画 | Claude Opus 5.5 根据 Endnd 的要求制作，Endnd 逐版审改 | `02_分镜/` |

| 字体 | HarmonyOS Sans SC、霞鹜文楷、站酷快乐体 | |

## 怎么看这些材料

| 文件夹 | 内容 | 怎么打开 |
|---|---|---|
| `01_剧本/` | 文字的完整流程 p0 → p5：给 DeepSeek 的提示词、语音转文字原稿、初稿、改稿、AI 占比估算；另有一份 Claude 写的更早版本（没有采用） | 直接看 |
| `02_分镜/` | 动态分镜：`claude网页版/` 是最早的几版，`index_v1` → `v8` → `index.html` 是本地迭代；`界面截图/` 是几张定稿截图 | **下载整个文件夹，双击 html 用浏览器打开**（需要和 `sprites.js` 放在一起） |
| `03_PV/` | 宣传 PV 的四版分镜和导出脚本 | 同上 |
| `04_提示词与交接/` | 给 AI 的美术关键词、UI 风格任务、换模型时写的交接文档 | 直接看 |
| `05_对话节选/` | 和 AI 的对话记录（每段标了模型），隐私信息已打码 | 直接看 |
| `06_发布/` | 试玩问卷、招募帖、封面 | 直接看 |
| `07_工具/` | 分镜和 Unity 之间的工具（本地服务器、表格转换、对话导出脚本） | 需要 Python |
