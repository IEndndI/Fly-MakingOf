# 英文版、日文版是怎么做的

2026.11.01，v1.2 加入了英文版和日文版。**译文全部由 Claude（Opus 5.5）翻译**，Endnd 在游戏里试玩、挑问题，没有逐句改译文。游戏里的创作声明页和「关于」页都写明了这一点。

## 这里有什么

| 文件 | 内容 |
|---|---|
| `story.txt` | 剧本译文：一行一句，`中文原句 ⇥ 英文 ⇥ 日文` |
| `ui.txt` | 界面文字译文，格式同上 |
| `About_en.txt` / `About_ja.txt` | 「关于」页的译文 |
| `EndCredits_en.txt` / `EndCredits_ja.txt` | 片尾名单的译文 |

## 做法

- **按原句查表，不另做一份译文剧本。** 游戏照常读中文剧本，显示每一句时拿中文原句去 `story.txt` 里查译文；查不到（比如新加的句子）就显示中文。这样在 WPS 里增删行、改分支，都不会让译文错位。
- **人名只在显示时翻。** 立绘是按中文 / 原名去找的，所以「妈妈」只在名牌上显示成 Mom / お母さん，程序内部还是「妈妈」。
- **画面和视频里画死的字不翻。** 标题画、分镜视频里的手写字保持中文；只有结尾最后那句手写字加了一行译文字幕。
- **选语言的界面放在创作声明之前**，第一次打开游戏时出现，之后可以在「设置」里改。

## 踩过的坑

- **译文比原文长。** 英文有 15 句超过对话框的三行（最长 6 行）。解决办法是加了一个翻页记号 `{p}`：打到这里停下、擦掉文本框、接着打。切在哪里由脚本按句号自动算，保证每页不超过三行。
- **`{p}` 和飞行段的「自动播放锁」打架。** 飞行段锁着自动播放，点击会被吃掉，翻页就永远等不到点击，整个游戏卡住。从中途跳进去测试时不会触发锁，所以一开始没发现；打包后 Endnd 实际玩到才发现。后来改成：锁住时跟着画面走，前面几页占整句几成字，就等画面走到这一段的几成再翻。
- **日文字体。** 中文字体里的汉字是中国写法，假名还要从别的字体借，混在一起不好看。日文版整套换成日文字体：正文 Klee One（霞鹜文楷就是从它改出来的，气质一样），界面 Zen Kaku Gothic New，两者都是 SIL OFL 1.1。中途遇到过几次乱码和字丢失（动态字体图集的问题），最后改成把日文用到的字全部提前画进静态图集。
