| BGM | 环境音 |
|---|---|
| 只有一首，用**一个变量** `currentFade` 存遥控器 | 可以有好几台，用**一本字典**存，每台录音机一个遥控器 |

## 报错：少了一个 `using`

`using` 的作用是告诉编译器「**去哪几个抽屉里找名字**」。C# 有成千上万个类，按命名空间分别放在不同的抽屉里。`SceneManager` 放在 `UnityEngine.SceneManagement` 这个抽屉里，你没告诉编译器去这里找，它就说「不存在」。

| `UnityEngine` | `MonoBehaviour`、`Debug`、`Application`、`AudioSource` | 几乎每个脚本都要 |
| `UnityEngine.UI` | `Image`、`Button` | 立绘、背景 |

| 原因 | 解释 |

## 动态字体：教你设置

先澄清一下性能的问题：之前说「性能消耗大」不算错，但要看场景。

| 类型 | 原理 | 代价 |
|---|---|---|
| 静态 | 提前把字烤进一张图集 | 运行时零开销，缺字就显示方块 |
| 动态 | 游戏中第一次遇到某个字时，现场生成并加进图集 | 每个字**只在第一次出现时**有一点开销。网游聊天这种随时可能冒出几千个新字的场景才需要担心；你的 demo 一共就几百个字，完全感觉不到 |

**设置步骤**（直接把 `MainFont` 改成动态，最省事）：

1. Project 窗口里点 `Assets/MainFont`
2. Inspector 里找到 **Generation Settings（生成设置）** 这一栏
3. **Atlas Population Mode（图集填充模式）**：`Static` 改成 **`Dynamic`**
4. 勾选 **Multi Atlas Textures（多图集纹理）**：一张图集装满后自动开新的一张，防止字多了装不下
5. 如果下面出现了 **Apply** 按钮，就点一下

原来烤好的字都会保留，缺的字会自动补上。以后 `CharacterExtractor` 加上重新生成字体这一套流程**都可以不用了**。

## Git：我做了什么、你怎么看、怎么用

### 我做了的三件事

| 操作 | 效果 |
|---|---|
| `git init -b main` | 在 `DEMO1` 里建了一个隐藏文件夹 `.git`，这就是**仓库本体**，所有历史版本都存在这里。删掉它就等于删掉全部历史，项目文件本身不受影响 |
| `git config user.name/email` | 设定这个仓库里提交的作者是谁。只对这个仓库有效 |
| 写了 `.gitignore` | 告诉 git 哪些东西**不用管**：`Library`、`Temp` 这类 Unity 随时能重建的缓存，一个就有好几 GB；还有 VS Code 生成的 `.csproj` 文件 |

**还没有任何提交**。现在仓库是空的，只是在「看着」你的文件。

### 怎么看：推荐 VS Code 自带的界面

你用 VS Code，所以不用记命令：

1. VS Code 打开 `DEMO1` 文件夹
2. 左边栏点**分叉图标**（Source Control / 源代码管理，快捷键 `Ctrl+Shift+G`）
3. 会列出所有「改过但还没提交」的文件，**点一个文件就能看到对比**：左边是旧版、右边是新版，红色是删掉的行、绿色是新加的行

在 Claude Code 里也能看，输入框里用 `!` 开头直接跑命令：

| 命令 | 作用 |
|---|---|
| `! git status` | 哪些文件改了、哪些还没提交 |
| `! git log --oneline` | 提交历史，一行一个 |
| `! git diff Assets/Script/AudioPlayer.cs` | 这个文件自上次提交以来改了什么 |

### 怎么用：你平时照常改文件，git 只在你**提交**的时候拍一张快照

| 想做的 | 怎么做 |
|---|---|
| 存一个版本 | Source Control 面板上方输入说明 → 点 **Commit（提交）** |
| 改坏了，想退回上次提交的样子 | 面板里右键那个文件 → **Discard Changes（放弃更改）** |
| 找回很久以前的版本 | 跟我说，我来查 `git log` 帮你取回来 |

**Unity 专属规矩**：每个资源旁边都有个 `.meta` 文件（存的是资源的 ID，场景和预制体靠它找到引用），**提交的时候要一起提交**。用「全部提交」就不会漏。

2. 点 Commit 旁边的 **✓**。如果提示「没有暂存的更改，要不要全部提交」，选 **Yes / Always**
