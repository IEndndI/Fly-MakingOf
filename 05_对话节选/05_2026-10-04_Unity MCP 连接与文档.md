新出现的东西：

| 写法 | 意思 |
|---|---|
| `Sprite[] frames` | 数组：一排按编号 0、1、2 排好的格子。你做过的花名册 `Dictionary` 是按名字查，数组是按编号查 |

    Image image;
    float timer;                // 距离上次换图过了几秒
    int index;                  // 现在显示第几张

    void Start()
    {
        image = GetComponent<____>();              // 空1：要拿哪个组件？
    }

    void Update()
    {
        timer += Time.____;                         // 空2：这个你在 FadeVolume 里写过
        if (timer >= 1f / fps)
        {
            timer -= 1f / fps;
            index = (index + 1) % ____;             // 空3：转到最后一张后回到 0

        }
    }
}
