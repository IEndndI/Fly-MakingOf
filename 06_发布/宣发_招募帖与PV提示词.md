## 二、PV 提示词（新对话里发给 Opus 5.5）

**附件：** `index.html` **和** `sprites.js` 一起传。HTML 里的图都从 sprites.js 读，只传 HTML 会缺图。

**复制下面整段：**

```
你是一位动态设计师。附件 index.html 是我的短篇视觉小说《飞 Fly》的「动态分镜」（单文件 HTML，图片资源在同目录的 sprites.js 里）。请你先通读它，弄懂它的视觉语言和剧情，再为游戏做第一支宣传 PV。

## 作品
- 《飞 Fly》：一个想飞的孩子，和他醒来以后的事。故事来自作者（Endnd，学生）多年前的一个梦。
- 五章：一 仲夏夜 / 二 最高的地方（第一次起飞，一路飞出宇宙）/ 三 折角 / 四 鸟群（人人都会飞的梦）/ 五 十一月（第二次起飞，失败），两个结局。
- 平台：Windows / 安卓。目前小范围试玩，人物立绘（兽设）会在之后的版本加入。
- AI 参与约 60%：故事、文本由作者写；画面、动画、程序、音乐由 Claude 完成。

## PV 要求
- 时长约 30 秒，横屏 16:9，舞台 1920×1080。这是第一支 PV，只负责「气质」和「想玩」，不讲完剧情。
- 风格：休闲、轻松、文艺。安静，有呼吸感，不要燃、不要快剪、不要预告片式的大字轰炸。
- 必须沿用分镜里已有的视觉语言：钴蓝 #0047AB、纸色 #F2ECDF、蜡笔黄 #F2B51F；瑞士平面网格（12 栏）；蜡笔线稿抖动（boil）；错版 / 套准标记；印刷品质感。可以直接复用 index.html 里的绘制函数和素材，不要另起一套画风。
- 开头先坦白 AI：第一屏用一行安静的小字，例如「本作由 AI 辅助制作（约 60%）· 故事与文本由作者完成」，停留约 2 秒后再进入正片。语气平和，不要道歉腔。
- 文案：主体只用游戏里的原句当字幕（从 HTML 的剧本数据里挑 3–5 句，比如章节引语「他忽然想，这大概就是最高的地方。」「飞翔好像和走路一样简单。」）。另外允许你写 1–2 句宣传语，但要克制、像诗，不要「震撼来袭」这类词；宣传语请单独列出来，标明是你写的，方便我替换。
- 结尾定版：标题「飞 Fly」+「一部视觉小说」+「Windows / Android」+「试玩招募中 · 详情见 QQ 空间」，停留 3 秒以上。
- 竖屏安全区：我之后会在 AE 里裁出 9:16 竖版。所有文字和关键主体要能放进画面正中间 608×1080 的竖条里；两侧只放可裁掉的氛围内容。请在 ?guide=1 时画出这条安全区参考线。

## 技术要求（重要，我要录屏后进 AE）
- 交付一个独立的 pv.html（可以 <script src="sprites.js">，和附件放同一目录）。
- 时间轴必须是确定性的：所有动画只由一个时间变量 t（秒）驱动，不依赖 setTimeout / CSS transition / 随机数（随机数请用固定种子）。
- 提供 window.pv = { duration, seek(t), play(), pause() }，并支持 URL 参数 ?t=12.5 直接跳到某一秒。这样我可以逐帧导出，不会掉帧。
- 默认打开后等空格键再开始播放，第 0 秒是干净的首帧，结尾停在定版画面不循环。
- 不要背景音乐和音效（我在 AE 里配），但请在 pv.html 顶部注释里写一张「节拍表」：每个镜头的起止时间、画面内容、建议的音乐起伏（比如「8.0s 音乐进入」「22.0s 收住，只留风声」）。
- 页面按窗口大小等比缩放舞台，不出滚动条。

## 交付顺序
1. 先给我一张镜头表（时间 / 画面 / 字幕 / 动效 / 用到 index.html 的哪部分），等我确认。
2. 我说「可以」以后，再写 pv.html。
```

**我的考虑：**
| 写法 | 为什么 |
|---|---|
| 先交镜头表、等确认再写代码 | 30 秒的片子方向错了很难改，先对齐镜头更省事 |
| 时间轴确定性 + `seek(t)` | 你之前录开场视频时，就是靠能逐帧控制才录出不掉帧的视频 |
| 竖屏安全区 608×1080 | 1080 × 9/16 ≈ 608，横版做完直接裁出竖版，不用重做 |
| 不要音乐，只要节拍表 | 你要进 AE 剪辑，音乐在 AE 里配更灵活 |
| 宣传语单独列出来 | 剧本是你的，它写的句子要能一眼认出来、方便你换掉 |
